# Changelog

## v0.2.2

- First public release with a generic application identifier and privacy-reviewed packaging.
- Compact two-row menu-bar display: RAM alert index above, CPU utilization below.
- White percentages on 50% opaque green, yellow, or red backgrounds.
- CPU warning above 80%; critical above 90%.
- Selectable refresh intervals: 1, 5 (default), 10, and 15 seconds, saved locally.
- Preserves the monitoring behavior from v0.2.1. Preferences from earlier private builds are not migrated.
